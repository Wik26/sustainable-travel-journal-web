# sustainable-travel-journal-web

## Project Overview
Mainly a front-end prototype to show how a sustainable travel journal functions. Users can calculate travel emissions and document their experiences.



## Responsibilities 
For this individual project, I developed a front-end based web application to simulate the functions of this website. This project was documentation heavy therefore the software is not as advanced as other projects.

## Technical Tools
- Front-end: HTML, CSS & JavaScript
- Database: used JavaScript localstorage to store user inputs.

## Key Features
- CO2 Calculator: Dynamically changes metrics on dashboard to display updated total emissions.
- CRUD Functionality: Users can add, view and delete their journals (not edit tho).
- Responsive Design: Enables users to resize, adheres to different screen sizes although not all.
